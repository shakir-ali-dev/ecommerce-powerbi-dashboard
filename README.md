# E-Commerce Analytics Dashboard | Power BI

An interactive 4-page Power BI dashboard analyzing the Brazilian E-Commerce 
Public Dataset by Olist — covering sales performance, customer behavior, 
delivery metrics, and customer satisfaction.

## 📊 Dashboard Pages

1. **Sales Overview** — Total revenue, orders, average order value, 
   revenue trends by year, category, and payment type
2. **Customer Insights** — Customer count, revenue by location, 
   top revenue-generating cities
3. **Delivery Performance** — Average delivery time, on-time delivery rate, 
   delivery performance by state
4. **Reviews & Satisfaction** — Average review score, score distribution, 
   top 10 product categories by rating

## 🛠️ Tools & Techniques
- Power BI Desktop (Data modeling, DAX, relationships)
- DAX measures: DISTINCTCOUNT, AVERAGEX, DATEDIFF, DIVIDE, CALCULATE, RANKX
- Data modeling across 8 relational tables
- Custom color theme, Top N filtering, data visualization best practices

## 📁 Dataset
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
